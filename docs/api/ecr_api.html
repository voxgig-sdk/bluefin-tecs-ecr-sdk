create

POST /makeTransaction

Operation ID: makeTransaction.

Authentication: bearer token (bearerAuth) or basic token (basicAuth).

Request body

application/json

Property Type Required Description
amount string Yes Numeric Transaction Amount. According to the ISO 4217 currency exponent, for example: - EUR (exponent = 2): 12,55 EUR is represented as "1255" - BYR (exponent = 0): 15000 BYR is represented as "15000"
authorization_number string No For Gratuity (msg type 0009): the authorization number of the original transaction. Otherwise, leave this field empty.
card_number string Yes Depends on the transaction scenario: - Standard Pin Pad transaction: leave empty. - Manual PAN input: provide card number + "" + expiration date (YYMM). - Swiped card on ECR: include Track2 data. - Cancellation/Capture (msg type 0013): "TXID" + original transaction number. - Gratuity (msg type 0009) or Credit note (msg type 0011): "TXID" + original transaction number. - Cancellation/Capture from different terminal: "TXID" + "" + "_" (for example, "TXID00000000001234567890_01_88091234").
currency string Yes ISO 4217 Alpha Currency Code (for example, "EUR", "USD").
cvc2 string No Card Verification Code.
desired_currency string No ISO 4217 Alpha Currency Code in which the transaction will be processed (for example, "EUR", "USD").
ecr_data string No ECR Data field used to transfer user information for private-labeled cards (for example, Fleet Card Company such as UTA, outex). This field is sent as received.
language string No ISO 639-1 language code used by the Pin Pad user interface during the transaction (for example, "en", "de", "es").
message_type string No Message type code. Allowed values include: - 0001 = Purchase, Balance, or Preauthorization - 0005 = Purchase with authorization number - 0009 = Gratuity - 0011 = Credit note - 0013 = Cancellation/Capture - 0015 = Pre-paid (Mobile Recharge) - 0017 = Abort ongoing transaction - 0018 = External reader device restart command - 0027 = Voucher/Coupon generation - 0029 = Card to Card transfer - 0034 = End of day (Internal TC only) - 2667 = Get connection status (Internal TC only) - 2668 = Terminal send diagnostic message (Internal TC only) - 4544 = Kill application (Internal TC only) - 9043 = Get terminal status - 9999 = Initiate CTLS tap event simulator - 7976 = Pops-up terminal system menu (Internal TC only)
password string No Password - currently not used (filled with spaces).
payment_reason string No Payment reason (for example, "Taxi journey"). Should be agreed with the acquirer. For Prepaid/Mobile recharge (msg type 0015): "+" followed by Operator Code and optional phone number. (UTF-8 encoded; maximum binary size is 39 bytes.)
payment_reasonAsByte array of string (byte) No Payment reason represented as a byte array.
personal_id string No Identification of the current user of the ECR or Terminal.
receipt_layout string No Receipt layout identifier.
receipt_number string No Receipt number.
terminal_number string Yes Terminal number provided by TECS. For Cancellation/Capture (msg type 0013), this is the terminal number of the original transaction.
transaction_date_time string Yes Transaction date and time (format: yyyymmddhhmmss).
transaction_id string Yes Unique transaction identifier. Must be unique for every transaction performed on the specified Terminal.
transaction_origin_identifier string No Transaction origin identifier: - 1 = Face to Face (Customer present) - 2 = MOTO (Customer not present) - 4 = Capture/Completion - 5 = Pre Authorization - 7 = Balance
transaction_origin_indicator string No Transaction origin indicator: - 0 = Request for card data on PIN PAD. - 1 = Face to Face (Magswipe on ECR, no PIN PAD). - 2 = Mail order/Telephone order/Manual entry (no PIN PAD).
transaction_place string No The transaction place; the first 5 characters should contain a formatted zip code.
transaction_source_id string No Identification number of the authorization source. In cancellation (msg type 0013), gratuity (0009), or credit note (msg type 0011), it should match the original transaction's source ID as provided by TECS.

Responses

200: successfully routed to TecsClient

*/*

Property Type Required Description
authorization_number string No Alphanumeric. Authorization number generated by TECS Authorization Host.
balance_amount string No Alphanumeric. Maximum amount available.
bonus_point string No Alphanumeric. Actual bonus points.
card_number string No Alphanumeric. Depends on the transaction scenario: - Standard transaction: Card number + "" + expiration date (YYMM). - For terminals activated for Card Reference number: "REF" + reference no + "" + expiry date (YYMM) + "" + last 4 digits from PAN + "" + first 6 digits from PAN. - Cancellation/capture/credit note: "TXID" + transaction number as entered in request. - Non ISO based Card numbers: Card prefix + Card number. Card prefixes are defined by TECS and are stated in the document "NonISO_CardIssuer_Prefixes" provided by TECS.
credit_card_issuer_and_acquirer_company string No Alphanumeric. Acquirer name + ";" + card brand (for example "VISA").
ecr_data string No Alphanumeric. ECR Data field used to transfer user information for private labeled cards like Fleet Card Company (for example UTA, outex, etc.). This field is sent from TECS Server to ECR as received.
ex_fee string No Numeric. Exchange fee.
exchange_rate string No Alphanumeric. Exchange rate at the time of transaction (for example 000000000000001,1223).
foreign_tx_amount string No Alphanumeric. Transaction amount in desired currency.
merchant_address string No Alphanumeric. Merchant address.
merchant_name string No Alphanumeric. Merchant name.
message_type string No Numeric. Message type: 0002 = Transaction response.
operator_id string No Alphanumeric. Identification of the operator of the TECS engine installation.
orig_stan string No Numeric. STAN of original transaction (for Cancellation).
orig_tx_id string No Numeric. Original transaction ID (for Cancellation).
receipt_footer string No Alphanumeric. Receipt footer that must be printed on the receipt. Contains the authentication method ("PIN VERIFIED" or "SIGNATURE") and tags "AID:" and "AC:".
receipt_header string No Alphanumeric. Receipt header.
response_code string No Numeric. Response code.
response_text string No Alphanumeric. Response text - description of the response code. Text is UTF-8 encoded. Binary size of the field is 80 bytes.
serien_nr string No Alphanumeric. If present, should be printed on the receipt.
stan string No Numeric. TECS Trace Number.
svc string No Numeric. Service code (returned by TECS Server). Must be printed on the receipt.
transaction_date_time string No Numeric. Transaction date and time (format: yyyymmddhhmmss).
transaction_id string No Alphanumeric. Transaction unique identifier (should be the same as sent in the authorization request).
transaction_type string No Alphanumeric. Transaction type.
vu_number string No Alphanumeric. Merchant Contract number with acquirer.
400: some error, explained in responseText
